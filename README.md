# Treb3rAntiCheater

Высокопроизводительный серверный Anti-ESP движок для Paper 1.21.x с повоксельной трассировкой лучей, поддержкой щелей/отверстий и сохранением ванильных ников.

---

## Архитектура

1. **Voxel Ray Marching Engine**:
   - Повоксельная трассировка лучей сквозь сложные многослойные препятствия (решётки, прутья, цепи, двери).
   - Автоматическая дискриминация сплошных и сквозных частей: сплошная нижняя часть деревянных и медных дверей (`Bisected.Half.BOTTOM`) и глухие рамы блокируют 100% лучей, а стеклянные проёмы и щели пропускают трассировку.
   - Сверхтонкие препятствия (прутья 2px, цепи, громоотводы, заборы, листва) исключены из ложной окклюзии — выступающие конечности и контуры игрока не пропадают при виде впритык.

2. **Multi-Tier Perimeter Sampling**:
   - Сканирование силуэта по 9 высотам (от подошвы обуви до макушки головы).
   - Сетка периметра хитбокса (передняя, задняя, левая, правая грани с шагом ~8.5 см + центральные оси). Гарантирует обнаружение игрока в узких щелях между сундуками, глиняными кувшинами и котлами даже при боковом взгляде (периферийное зрение).
   - Прямой луч `Eye-to-Eye` и трассировка прицела `Crosshair-to-Hitbox`.

3. **Ephemeral Nametag Passthrough**:
   - При скрытии 3D-модели игрока за стеной (полная блокировка Box ESP, Skeleton ESP, Chams, Tracers) ванильный ник проецируется через изолированный пакетный `TextDisplay`.
   - Полное сохранение ванильной ориентировки по никам без утечки координат хитбокса.
   - Автоматически скрывает ник, если игрок присел (Shift) — строго по ванильной механике.

4. **Debounced Hysteresis**:
   - 8-тиковый (400 мс) гистерезис видимости для устранения мерцания (flicker) на гранях блоков.
   - Изолированный per-viewer кэш сущностей (предметы, мобы, стойки для брони).

5. **Client Camera Protocol**:
   - Поддержка плагин-канала `treb3r:camera` для синхронизации F5-камеры от клиентских модов.

---

## Команды и права

- `/treber reload` — перезагрузка `config.yml` на лету (право: `treb3r.admin`).
- `/treber status` — текущие параметры движка и активные фильтры.
- Право обхода окклюзии: `treb3r.bypass` (или режим зрителя Spectator).

---

## Конфигурация (`config.yml`)

```yaml
# Максимальная дистанция трассировки (сущности дальше скрываются)
max-tracking-distance: 48.0

# Дистанция гарантированной видимости (0.0 = строгая окклюзия в упор)
near-distance: 0.0

# Тайм-слайсинг нагрузки (1 = каждый тик real-time, 2 = 50% CPU)
time-slices: 1

# Учёт ванильного свечения (Spectral Arrow, Bell, Glowing Effect)
bypass-on-glowing: true

# Длительность взаимной видимости после удара (30 тиков = 1.5 сек)
combat-grace-ticks: 30

# Типы сущностей для окклюзии:
hide-players: true
hide-monsters: true
hide-animals: false
hide-misc: true
```

## Сборка

Требования: **Java 21 LTS**, **Maven 3.9+**.

```bash
mvn clean package
```

Готовый JAR появится в папке `target/Treb3rAntiCheater-1.0.0.jar`.
