# Treb3rAntiCheater

Высокопроизводительный серверный комплекс защиты для Paper 1.21.x:
1. **Hardened Anti-ESP** — повоксельная трассировка лучей, сохранение ванильных ников, поддержка щелей и микро-отверстий.
2. **Native Packet Anti-Xray** — встроенная в плагин обфускация пакетов чанков на лету (Engine Mode 2) без ручной правки конфигов сервера.

---

## Архитектура

### 1. Packet Anti-Xray Engine
- **In-Memory Injection**: плагин автоматически перехватывает сетевой контроллер чанков Paper (`ServerLevel.chunkPacketBlockController`) через рефлексию и активирует `ChunkPacketBlockControllerAntiXray`.
- **Engine Mode 2 (Обфускация рудами)**: все скрытые в недрах породы блоки руд подменяются на ложные блоки (алмазы, золото, железо, медь, лазурит, незерит) непосредственно перед отправкой чанка клиенту. При включении чита X-Ray игрок видит хаотичную стену из фейковых руд.
- **Engine Mode 1 (Маскировка камнем)**: скрывает закрытые руды под видом обычного камня, глубокого сланца или незерака.
- **Zero Config**: не требует ручной настройки `paper-world.yml` — всё управляется из `plugins/Treb3rAntiCheater/config.yml`.
- **Lava Obscuring**: автоматическое скрытие руд под лавовыми озёрами.
- **De-obfuscation**: как только блок добывается легитимным путём, окружающие блоки мгновенно обновляются до реального состояния.

### 2. Voxel Ray Marching Anti-ESP
- **Повоксельная трассировка**: автоматическая дискриминация сплошных и сквозных частей. Сплошная нижняя часть деревянных и медных дверей (`Bisected.Half.BOTTOM`) и глухие рамы блокируют 100% лучей, а стеклянные проёмы и щели пропускают видимость.
- **Исключение ложной окклюзии**: тонкие препятствия (прутья 2px, цепи, громоотводы, заборы, листва) пропускают лучи к выступающим конечностям игрока при виде в упор.
- **Multi-Tier Perimeter Sampling**: сканирование по 9 высотам и по 4 граням хитбокса (~8.5 см шаг). Игрок мгновенно отрисовывается в узких щелях (между сундуками, глиняными кувшинами) даже при периферийном взгляде.
- **Ephemeral Nametag Passthrough**: при скрытии 3D-тела за стеной ванильный ник проецируется через `TextDisplay`. Если игрок крадётся (Shift), ник скрывается.
- **Zero-Flicker Debounce**: 8-тиковый гистерезис видимости для устранения мерцания.
- **Client Camera Protocol**: поддержка канала `treb3r:camera` для F5-камеры.

## Команды и права

- `/treber reload` — перезагрузка `config.yml` и обновление контроллеров на лету (право: `treb3r.admin`).
- `/treber status` — статус работы Anti-ESP и Anti-Xray.
- Право обхода защиты: `treb3r.bypass` (или режим зрителя Spectator).

## Конфигурация (`config.yml`)

```yaml
# ==========================================
# 1. Anti-ESP & Occlusion Culling
# ==========================================
max-tracking-distance: 48.0
near-distance: 0.0
time-slices: 1
bypass-on-glowing: true
combat-grace-ticks: 30
hide-players: true
hide-monsters: true
hide-animals: false
hide-misc: true

# ==========================================
# 2. Packet-Level Anti-Xray Engine
# ==========================================
anti-xray:
  enabled: true
  engine-mode: 2  # 1 = hide (камень), 2 = obfuscate (фейк-руды)
  lava-obscures: true
  update-radius: 2
```
